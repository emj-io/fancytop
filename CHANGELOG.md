# Changelog

## 0.2.0

- Tiling window manager for the panels: drag borders to resize, drag title bars to move, keyboard focus,
  swap, resize, split flip and zoom.
- Eleven colour themes (`-t`, `c` / `C`).
- Disk and network throughput panel.
- Process list.
- `--snapshot WxH` prints one frame as plain text.
- Quits and restores the terminal on SIGINT, SIGTERM and SIGHUP.
- A panicked sampler thread no longer takes the UI down with it.

## 0.1.0

- First Rust version: per-core CPU, GPU, memory and DRAM bandwidth.
